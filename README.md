# MEMETRIC

Веб-прототип игры **MEMETRIC**: ритм-платформер, где уровни вдохновлены эпохами интернет-культуры.

## Что реализовано

- 4 сюжетных уровня:
  - Doge Awakens
  - Skibidi Toilet Panic
  - Hawk Tuah Mania
  - Жиза (секретный босс)
- Переключаемый **Тренд-режим** (еженедельный мини-уровень, пример — Barbieverse).
- Механики:
  - прыжки (включая двойной прыжок на поздних уровнях);
  - атака звуковой волной в боевых фазах;
  - коллизии, жизни, очки, ускорение ритма.
- Визуальная стилистика: pixel/vaporwave-палитры и динамичный HUD.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Управление

- `Space` / `W` — прыжок
- `K` — "Hawk Tuah" атака (на соответствующих уровнях)
- `T` — активировать тренд-режим
- Кнопки в интерфейсе: Старт / Пауза / Тренд недели
